# AI session logs

Assessment requirement: export the transcript of every AI session into `ai-logs/`.

## How to export Cursor chats (do not fabricate)

1. Open each Composer / Agent chat used for this repo in Cursor (including earlier billing/API sessions and this UI/docs session).
2. Export or copy the full transcript from the chat UI (thread menu, “…” controls, or Command Palette → search for export/copy chat). Cursor may also keep agent transcripts under your local Cursor project folder; if you copy those files, paste them here unchanged.
3. Save each export as a separate file in this folder, for example:
   - `ai-logs/01-billing-and-schema.md`
   - `ai-logs/02-api-and-payments.md`
   - `ai-logs/03-ui-and-docs.md`
4. Prefer the full unedited transcript. Do not rewrite answers to look cleaner, and do not invent sessions that did not happen.
5. If export is unavailable, paste the complete chat history from the UI into a markdown file and note the export date at the top.
6. `DECISIONS.md` §6 cites two real mistakes from this work (wrong first billing/schema draft; gateway tests polluting Aisyah’s lease). Those passages must appear in the exported logs.

## What graders look for

Not how much AI you used — how you directed it, what you checked, and what you corrected. The mistakes called out in `DECISIONS.md` §6 must appear in these transcripts.
